# Data Structures Lab Project

A Python console application that implements custom data structures, demonstrates their practical use, and compares their performance with benchmarks.

## Implemented Data Structures

- **Array:** Fixed-capacity array with indexed access, insertion, deletion, and search.
- **Dynamic Array:** Resizable array that doubles its capacity when full and shrinks when it becomes quarter-full.
- **Singly Linked List:** Linked nodes with a single `next` pointer.
- **Doubly Linked List:** Linked nodes with `prev` and `next` pointers.
- **Stack:** LIFO structure implemented using the Dynamic Array.
- **Queue:** FIFO structure implemented using the Doubly Linked List.
- **Deque:** Double-ended queue implemented using the Doubly Linked List.
- **Hash Table:** Hash table using separate chaining for collision resolution and automatic resizing.
- **Binary Search Tree (BST):** Supports insertion, searching, deletion, traversal, and height calculation.

## Practical Applications

The project demonstrates Stack, Queue, and Deque through three small applications:

- **Undo/Redo:** Uses two stacks to manage editing history.
- **Print Queue:** Uses a queue to process print jobs in FIFO order.
- **Recent Browsing History:** Uses a deque to store the five most recent pages.

## Requirements

- Python 3.12 or later
- No external Python packages required

## Running the Application

Clone the repository:

```bash
git clone https://github.com/zeIbdo/DSAGroupFreeWork.git
```

Navigate to the project directory:

```bash
cd DSAGroupFreeWork
```

Run the application:

```bash
python main.py
```

The application provides a menu for running benchmarks and exploring the implemented data structures.

## Running Tests

Run the automated test suite:

```bash
python test_structures.py
```

The test suite contains 51 checks covering normal operations, edge cases, empty structures, invalid operations, collisions, resizing, and BST deletion scenarios.

## Performance Benchmarks

The project measures performance using Python's `time.perf_counter_ns()`.

Test sizes:

- 100 elements
- 1,000 elements
- 10,000 elements

The benchmarks cover:

- Array and Dynamic Array insertion, deletion, and search.
- Singly and Doubly Linked List operations.
- Stack, Queue, and Deque operations.
- Hash Table operations compared with linear array search.
- BST performance with random and sorted insertion orders.

Results are displayed in the console in microseconds. The benchmark inputs are generated by the program, so exact timings can vary between runs and computers.

## Complexity Overview

| Data Structure | Search | Insertion | Deletion |
|---|---:|---:|---:|
| Array | O(n) | O(1) at end, O(n) elsewhere | O(1) at end, O(n) elsewhere |
| Dynamic Array | O(n) | O(1) amortized at end | O(1) amortized at end |
| Singly Linked List | O(n) | O(1) at start, O(n) at end | O(1) at start, O(n) at end |
| Doubly Linked List | O(n) | O(1) at both ends | O(1) at both ends |
| Stack | - | O(1) amortized | O(1) amortized |
| Queue | - | O(1) | O(1) |
| Deque | - | O(1) at both ends | O(1) at both ends |
| Hash Table | O(1) average, O(n) worst | O(1) average | O(1) average |
| BST | O(log n) expected for random insertion, O(n) worst | O(log n) expected, O(n) worst | O(log n) expected, O(n) worst |
